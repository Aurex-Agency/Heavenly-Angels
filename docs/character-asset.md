# Dove asset

Generated using the built-in image generation tool, using the prior approved-direction concept sheet as reference. The PNG was encoded as WebP for delivery with alpha preserved. No rig or independent wing animation is implied; the first build animates the whole illustration on entry.

Prompt: Create a single production website cutout of the exact ivory dove mascot in this reference character sheet. Preserve its identity: ivory pear-shaped body, glossy navy oval eyes, small peach beak and feet, sky blue neck scarf, sculpted matte clay feathers. Full body, facing slightly left toward website copy, welcoming pose with one wing raised outward. Sophisticated friendly 3D render, soft studio lighting and very subtle contact shadow. Large character centered and completely uncropped, clear edges, genuinely transparent background. No text, no sheet, no panels, no palette, no other objects. Match the reference Welcome dove faithfully.

The rendered result faces slightly right; it is retained as a first-round composition. Asset: public/assets/dove.webp. The original concept sheet remains in the parent workspace's design/characters directory.

## Scroll journey update

A second original flying pose was generated with the same reference sheet using the built-in image tool. Asset: `public/assets/dove-flight.webp` (1374×1145, alpha preserved).

Prompt: Create a single full-body cutout of the exact ivory dove mascot with blue scarf from this reference, airborne with both wings spread out and lifted in a joyful mid-flight pose, feet gently tucked. Same ivory matte clay sculpted body, navy oval eyes, peach beak and feet and blue scarf. Three-quarter view facing viewer, wings anatomically attached, open friendly expression, premium 3D render. Entire bird and wings within frame, ample transparent margin. No text, panels, props or shadow floor. Genuine transparent background. The homepage now combines standing/flying crossfades, scroll-linked travel/rotation/scale, scene color changes, moving decorative objects, and a slow idle float.
